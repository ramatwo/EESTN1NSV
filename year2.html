2° Año: Desarrollo Web y Estructuras de Datos

Profundiza tus conocimientos en programación y explora el mundo del desarrollo web

Descripción del Programa

El segundo año profundiza en los conceptos de programación y introduce a los estudiantes en el desarrollo web básico y las estructuras de datos fundamentales.

Materias

  • Programación Orientada a Objetos (Java)
  • Introducción al Desarrollo Web (HTML y CSS)
  • Estructuras de Datos Básicas
  • Redes de Computadoras I
  • Diseño Gráfico Digital

Proyectos Destacados

  • Desarrollo de un juego simple en Java
  • Creación de una página web personal
  • Implementación de estructuras de datos básicas
  • Diseño de un logo para una empresa ficticia

Preguntas Frecuentes

¿Cómo se relaciona el contenido de 2° año con el de 1° año?

El segundo año se basa en los fundamentos aprendidos en el primer año, profundizando en la programación y expandiendo hacia nuevas áreas como el desarrollo web.

¿Necesito mi propia computadora para las clases de desarrollo web?

Aunque la escuela proporciona computadoras, es recomendable tener acceso a una computadora en casa para practicar y trabajar en proyectos.
